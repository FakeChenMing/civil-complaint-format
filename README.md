# 民事起诉状固定格式

按固定格式起草或核对民事起诉状，附可编辑 Word 母版、格式参数与结构检查脚本。

下载 [civil-complaint-format.zip](civil-complaint-format.zip)，解压后将整个 `civil-complaint-format` 文件夹放入技能目录。保留子目录，先阅读包内的 `SKILL.md` 及所列依赖。

版本依据为 2026 年 9 月 29 日打包版。公开副本已移除内部案件来源和个人路径。

母版使用占位字段。检查脚本依赖 Python 和 python-docx。在技能目录中运行 `python scripts/check_complaint.py --template assets/民事起诉状-固定格式母版.docx` 可复核母版结构。
